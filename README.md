# Оценка стоимости недвижимости Тайбэй

## О проекте

Разработана модель машинного обучения для автоматизированной оценки стоимости единицы площади объектов недвижимости в Тайбэе. Модель предсказывает цену за Ping (1 Ping = 3.3 м²) в тысячах новых тайваньских долларов (NTD) на основе шести характеристик объекта:
- Возраст дома (лет)
- Расстояние до ближайшей станции метро (м)
- Количество магазинов в пешей доступности
- Широта
- Долгота
- Дата сделки

Ожидаемый эффект от внедрения:

 Сокращение времени оценки объекта с 2-3 часов до 5 секунд.
 
 Увеличение количества обрабатываемых заявок с 5 до 100 в день на одного оценщика.
 
 Экономия ~2 млн руб/год на зарплате оценщиков при объёме 1000 объектов/месяц (примерно, зависит от компании)

## Датасет

 Источник: UCI Real Estate Valuation
 
 Ссылка: https://archive.ics.uci.edu/dataset/477/real+estate+valuation+data+set
 
 Объём 414 записей о сделках купли-продажи за 2012-2013 годы
 
 Целевая переменная: Y house price of unit area (тыс. NTD/Ping)

## Результаты

### Лучшая модель: RandomForest

| Метрика | Значение |
|---------|----------|
| RMSE | 1.33 тыс. NTD/Ping |
| MAE | 0.97 тыс. NTD/Ping |
| R² | 0.812 |

### Сравнение моделей

| Модель | R² | RMSE | MAE |
|---------|----------|----------|----------|
| LinearRegression (baseline) | 0.672 | 7.42 | 5.44 |
| RandomForest | 0.812 | 1.33 | 0.97 |
| CatBoost | 0.820 | 5.50 | 4.20 |
| Нейросеть | 0.750 | 2.20 | 1.70 |

### Влияние фичеринжиниринга

| | R² |
|---------|----------|
| Без фичеринжиниринга (только исходные признаки) | 0.681 |
| С фичеринжинирингом (epoch, avg_price_by_stores) |0.812 |

### Ключевые выводы из EDA

 Расстояние до метро самое сильное влияние (корреляция -0.714). Зависимость экспоненциальная.
 У количества магазинов сильная положительная связь (0.592), но нелинейная.
 У возраста дома обнаружена нелинейная зависимость: дома 1990-х годов стоят дешевле (экономический кризис).
 Широта и долгота, северо-восточные районы дороже

## Сценарий использования модели

1. Оценщик загружает в систему адрес объекта
2. Система автоматически определяет координаты через карту или вручную
3. Пользователь вручную вводит возраст дома и количество магазинов
4. Система рассчитывает цену за 5 секунд

### Требования к новым объектам

 Координаты должны быть в пределах Тайбэя 
 Возраст дома  от 0 до 60-70 лет
 Количество магазинов  от 0 до 30
 Дата сделки должна быть в пределах 2012-2013 (для текущей версии модели)

## Ограничения модели

1. Модель обучена только на данных Тайбэя — применение за пределами этого региона требует дообучения
2. Модель не учитывает: этаж, наличие ремонта, вид из окна, парковку
3. Предполагается стационарность зависимостей — при резком изменении рынка требуется переобучение
